# Privacy Policy — KnowNow

KnowNow is an offline reader for publicly available ServiceNow documentation.

- No personal data is collected by the app.
- Downloaded documentation and user notes are stored locally on the device.
- Optional GitHub token entered in Settings is stored in Android DataStore on the device and is only used to make GitHub API requests.
- The app does not include analytics or crash reporting.
- Links to servicenow.com or github.com open in the user's browser, subject to those sites' policies.
